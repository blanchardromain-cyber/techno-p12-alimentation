Toutes les pages sont **non notées** : aucun envoi, aucune donnée personnelle. La progression reste dans le
navigateur du poste (bouton « Recommencer » pour l'effacer). Chaque page suit la démarche d'investigation
(question → hypothèse → j'investigue → je conclus → je retiens), propose une version imprimable et charge les
aides dys du site Technologie (`assets/js/confort-lecture.js`, `assets/js/lecture-immersive.js`).

## Vocabulaire de référence

Toutes les pages emploient les formulations de la synthèse P12 (FT1 « Dissiper la chaleur vers l'extérieur »
→ condenseur … FT6 « Transporter la chaleur » → fluide frigorigène ; 4 domaines : matériaux, énergie, fonctions,
connexion ; non mécanisé / mécanisé / automatisé ; 4 symboles d'algorigramme ; CEI 60884-1 ; IEEE 802.11ah).

## Adresses utiles pour projeter

- `robot-balance.html?corrige` remplit toutes les étapes ; `robot-balance.html?corrige&auto` lance la recette seule.
- `circuit-du-froid.html#pas-1` à `#pas-6` : une étape du circuit.
